# Казань рядом

Telegram-путеводитель по историческому центру Казани и татарской культуре. Python 3.9+ и aiogram 3.13.1: версия закреплена для воспроизводимого запуска. Это обычный Telegram-бот с карточками, эмодзи, фотографиями и кнопками. Цвета интерфейса чата определяет приложение Telegram; отдельная карта оформлена в зелёных и золотых тонах.

## Что готово

- 15 достопримечательностей и 3 гастрономические остановки с авторскими описаниями.
- 5 вариантов дня: первое знакомство, 12 исторических остановок, татарская культура, семейный день, день в дождь.
- Поиск по названиям и описаниям, случайное место, избранное.
- Ссылки на Яндекс Карты, фотографии посетителей, отзывы в 2ГИС и источники.
- Фото объектов из Wikipedia/Wikimedia с автором, лицензией и ссылкой на страницу файла. Для кафе используется подписанная иллюстрация татарской кухни.
- Реальные отзывы пользователей бота: оценка 1–5, текст и модерация. Начальных вымышленных отзывов и рейтингов нет.
- Интерактивная карта `map.html`, которую бот отправляет файлом. В ней есть все остановки и переключатель маршрутов.
- SQLite сохраняет избранное и отзывы после перезапуска.

## Запуск на Mac или Linux

1. Создайте бота в официальном [@BotFather](https://t.me/BotFather): `/newbot`, затем название и уникальное имя, заканчивающееся на `bot`. Сохраните токен.
2. Распакуйте архив и откройте терминал в папке `kazan_bot`.
3. Выполните:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
```

4. Откройте `.env` в редакторе. Вставьте токен вместо `PASTE_TOKEN_FROM_BOTFATHER`:

```dotenv
BOT_TOKEN=ваш_токен
ADMIN_ID=0
MAP_URL=
```

5. Запустите:

```bash
python bot.py
```

6. Откройте своего бота в Telegram и нажмите **Start**.

Токен должен оставаться только в `.env`. Если токен раскрыт, перевыпустите его через BotFather. Компьютер и программа должны работать, чтобы бот отвечал; для постоянной работы перенесите папку на сервер. Не запускайте одновременно несколько процессов с одним токеном. Если `python3` старее 3.9, используйте установленный Python 3.11 или 3.12.

## Отзывы и модерация

Укажите свой числовой Telegram ID в `ADMIN_ID` и перезапустите бота. Его можно узнать у бота получения ID, которому вы доверяете, либо из объекта `message.from_user.id` при локальной отладке. Сначала напишите своему боту `/start`, чтобы он мог отправлять вам сообщения.

До настройки администратора отправка отзывов отключена; внешние отзывы доступны всегда. После настройки новые отзывы попадают в очередь и публикуются кнопкой администратора. `/pending` показывает первые 20 ожидающих отзывов; повторите после обработки. Повторный отзыв пользователя на то же место заменяет прежний и снова требует проверки. Старые кнопки модерации не публикуют новую редакцию отзыва.

В базе хранятся Telegram ID, избранное, оценки, тексты и время отзывов. Публичная подпись — «Гость». `/delete_me` удаляет данные пользователя из рабочей базы. Не включайте базу в публичный репозиторий. Незавершённая форма отзыва хранится в памяти и сбрасывается при перезапуске. Для учебного проекта достаточно одного процесса; для большой аудитории нужны дополнительные меры против спама и миграции базы.

## Фотографии

Бот получает фотографии при открытии карточки; повторные запросы используют часовой кеш в памяти. Для работы нужны доступ к Wikipedia/Wikimedia и Telegram. При отсутствии фото или сетевой ошибке карточка с описанием и ссылками остаётся доступна. Первое открытие может занять несколько секунд. Внешние ресурсы могут быть недоступны в отдельных сетях.

Можно заменить динамические фотографии своими: создайте папку `photos`, положите `photos/kremlin.jpg` (и аналогично для других ключей из `content.py`) и укажите сведения в `photo_credits.json`:

```json
{
  "kremlin": {
    "author": "Имя автора",
    "license": "Собственное фото, разрешено использование",
    "url": "https://example.com/photo-source"
  }
}
```

Используйте только изображения, на которые у вас есть права. Для локальных фото кафе при необходимости измените подпись в функции `card` в `bot.py`: по умолчанию она описывает фотографию как иллюстрацию кухни. Сохранённая в архиве карта содержит ссылки на фотографии, сами снимки не включены в архив.

## Маршруты и карта

`content.py` содержит весь контент, координаты и расписания. После правок выполните `python build_map.py`, чтобы обновить `map.html`. Для просмотра карты скачайте файл, отправленный ботом, и откройте в браузере. Нужен интернет для Leaflet и OpenStreetMap. Чтобы открывать карту сразу по кнопке, разместите `map.html` на HTTPS-хостинге и впишите адрес в `MAP_URL`.

Координаты приблизительные, линия карты показывает порядок остановок, а не безопасный проход между ними. Кнопка навигатора строит пешие переходы. Точка «Тюбетей» — район центра: конкретный филиал выбирают на сайте сети. Семейный маршрут требует транспорта между Кремлём и театром. В большом маршруте планируется короткий музейный обзор, внешний осмотр части объектов и паузы на еду. Не пытайтесь пройти его с подробным посещением каждого музея.

Время приблизительное. Проверяйте расписания, доступность зданий, молитвы, билеты и меню на дату поездки. Цены и актуальные числовые рейтинги не зафиксированы, чтобы не выдавать устаревшие данные. Внешние отзывы открываются на платформе, бот их не копирует.

## Для защиты учебного проекта

Тематика: исторический центр Казани как пространство взаимодействия татарской и русской культур. Оригинальное название: «Казань рядом — город двух культур». Большой маршрут включает 12 остановок и объясняет смысл переходов: Кремль и религия → река и современная архитектура → музейная история → городской центр → татарская слобода и озеро. Раздел «О Казани» раскрывает географию, культуру, экономику, религию, известных людей и кухню. Карта с остановками, фото и источники доступны из бота.

Пример демонстрации: `/start` → большой маршрут → Кул Шариф → карта → кафе → отзыв → модерация → избранное. Итоговую презентацию по заданию нужно подготовить отдельно.

## Проверка

```bash
python -m unittest discover -s tests -v
python -m compileall -q .
```

Тесты проверяют контент маршрутов, длину callback, хранение избранного, публикацию отзывов, защиту от старых кнопок модерации и удаление пользовательских данных. Реальную доставку сообщений и получение снимков проверяйте после запуска с вашим токеном.
